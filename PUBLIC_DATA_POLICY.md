# Public Data Policy

This repository is intended for public distribution.

## Allowed source material

- publicly accessible vendor documentation,
- public research papers and technical reports,
- public open-source repositories,
- public benchmark/evaluation pages,
- generic synthetic examples created specifically for this repository.

## Prohibited source material

Do not commit, quote, paraphrase, encode, or derive examples from:

- private conversations,
- private user memories or profiles,
- private medical or patient information,
- internal organisational documents,
- proprietary benchmarks or unpublished evaluation results,
- confidential source code or credentials,
- private document corpora.

## Contribution rule

If a contribution is based on a non-public system, generalise the lesson and replace all examples, names, numbers, traces, screenshots, and identifiers with independently created public or synthetic material before submission.

## Evaluation data

The skills may instruct an agent to evaluate a user's private system locally or within that user's authorised environment. Such evaluation data belongs to that environment and must not be copied into this public repository.
